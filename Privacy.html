개인정보처리방침

NewSchool(이하 '서비스')은 이용자의 개인정보를 중요시하며, 「개인정보 보호법」 등 관련 법령을 준수하기 위해 최선을 다하고 있습니다. 본 방침은 서비스가 수집하는 개인정보의 항목, 이용 목적, 보관 및 파기 절차 등에 대해 안내합니다.

1. 수집·처리하는 정보 항목

서비스는 Windows PC에 설치되어 동작하는 데스크톱 프로그램이며, 별도의 서버를 운영하지 않습니다. 이용자가 입력한 학생·학급·수업 기록은 모두 이용자의 PC에만 저장되며, 서비스 운영자를 포함해 누구에게도 전송되지 않습니다. 프로그램이 바깥과 통신하는 경우는 아래 세 가지뿐입니다.

  • Google Calendar — 이용자가 직접 연동했을 때만. 아래 항목을 주고받습니다.
  • 나이스(NEIS) 교육정보 개방 포털 — 학사일정·급식 식단을 받아오고 학교를 검색할 때. 보내는 값은 학교 코드·시도교육청 코드·조회 날짜와 이용자가 입력한 학교 이름 검색어뿐이며, 학생 정보나 이용자가 입력한 기록은 보내지 않습니다.
  • GitHub — 새 버전이 나왔는지 확인할 때. 공개된 버전 정보만 내려받고, 보내는 데이터는 없습니다.
  • Google Calendar 데이터: 이용자가 동기화 대상으로 선택한 캘린더의 일정 제목, 설명, 장소, 시작·종료 일시, 반복 규칙, 색상, 일정 식별자(ID), 최종 수정 시각, 일정 상태(확정·취소 구분).
    할 일로 등록한 항목은 할 일 여부·완료 여부·완료 시각을 일정의 비공개 속성(private extended properties)에 함께 기록하여, 프로그램과 Google 캘린더 양쪽에서 같은 상태로 보이게 합니다.
    ※ 일정의 참석자 정보, 주최자·작성자 이메일, 첨부파일, 화상회의 링크는 요청하지도 저장하지도 않습니다.
  • Google 인증 토큰: OAuth 2.0 액세스 토큰 및 리프레시 토큰
  • 학사 관리 데이터: 이용자가 프로그램에 직접 입력한 학급·수업·업무 일정 등 (이용자 PC의 로컬 데이터베이스에만 저장)

서비스는 이용자의 이메일 주소·이름·프로필 사진 등 계정 프로필 정보를 요청하지 않으며 수집하지 않습니다. Google 로그인은 캘린더 접근 권한을 위임받는 용도로만 사용되고, 회원 식별에는 사용되지 않습니다.

2. 이용 목적

  • Google 캘린더 양방향 동기화: 프로그램에 입력한 학사일정·수업·학급·업무 일정을 Google 캘린더에 반영하고, Google 캘린더에서 변경된 내용을 프로그램으로 가져오는 기능 제공
  • 전용 캘린더 생성: 이용자의 기존 캘린더와 학교 일정이 섞이지 않도록 학교 전용 보조 캘린더를 생성

수집된 Google 사용자 데이터는 위 기능 제공 목적 외에 사용되지 않으며, 광고·프로파일링·AI 모델 학습에 사용하지 않습니다. 또한 제3자에게 판매·양도·공유하지 않습니다. NewSchool의 Google API 사용은 Google API Services User Data Policy의 Limited Use 요건을 준수합니다.

3. 요청하는 Google 권한 범위(Scope)

  • calendar.calendarlist.readonly — 동기화할 캘린더를 이용자가 선택할 수 있도록 캘린더 목록을 읽습니다.
  • calendar.calendars — 학교 일정 전용 보조 캘린더를 생성합니다.
  • calendar.events — 선택된 캘린더의 일정을 읽고, 만들고, 수정하고, 삭제합니다. (양방향 동기화에 필요)

서비스는 캘린더의 공유 설정(ACL) 변경, 캘린더 자체의 삭제, 다른 Google 서비스(Gmail·Drive 등) 접근 권한을 요청하지 않습니다.

4. 저장 방식 · 보관 기간 · 삭제 방법

  • 저장 위치: 모든 일정 데이터와 인증 토큰은 이용자 PC의 로컬 데이터베이스 파일에만 저장됩니다. 서비스 운영자는 이용자의 데이터에 접근할 수 없습니다.
  • 토큰 보호: Google 인증 토큰은 Windows DPAPI(현재 사용자 계정 전용 암호화)로 암호화하여 저장합니다.
  • 보관 기간: 이용자가 연동을 유지하는 동안 보관하며, 별도의 만료 기간을 두지 않습니다.
  • 삭제 방법:
    1. 프로그램의 달력 화면에서 상단 ⚙ 캘린더 설정 버튼을 누른 뒤 Google 연동 해제를 실행하면, Google에 토큰 무효화(revoke)를 요청하고 PC에 저장된 토큰을 즉시 삭제합니다.
    2. Google 계정 권한 관리에서 NewSchool의 접근 권한을 직접 철회할 수 있습니다.
    3. 프로그램을 삭제하고 데이터 폴더를 제거하면 로컬에 저장된 일정 사본도 모두 사라집니다.
  • Google로 전송된 일정: 연동 해제 후에도 이미 Google 캘린더에 생성된 일정은 그대로 남습니다. 이용자가 Google 캘린더에서 직접 삭제할 수 있습니다.

5. 개인정보의 제3자 제공 및 위탁

서비스는 이용자의 동의 없이 개인정보를 외부에 제공하거나 위탁하지 않습니다. 단, 법령의 규정에 의거하거나 수사 목적으로 법령에 정해진 절차와 방법에 따라 수사기관의 요구가 있는 경우는 예외로 합니다.

6. 이용자의 권리 및 행사 방법

이용자는 언제든지 자신의 개인정보에 대해 조회, 수정, 연동 철회를 요청할 수 있습니다. Google 계정 연동 권한은 Google 계정 보안 페이지에서 직접 철회하실 수 있습니다.
