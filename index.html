⚠️ 내려받을 때 “일반적으로 다운로드되지 않습니다” 경고가 뜹니다

NewSchool 은 코드 서명 인증서 없이 배포하고 있습니다. 인증서는 해마다 비용이 드는데, 무료로 만들어 나누는 프로그램이라 아직 붙이지 못했습니다.

그래서 Windows 의 SmartScreen 이 “아직 내려받은 사람이 적은 파일” 이라고 알립니다. 바이러스를 찾았다는 뜻이 아니라, 이 파일을 아직 잘 모르겠다는 뜻입니다. 내려받은 분이 늘면 사라지지만, 새 버전을 낼 때마다 처음부터 다시 쌓입니다.

설치하는 방법

  1. 다운로드가 막히면 — 브라우저의 다운로드 목록에서 파일 옆 ⋯ → 유지
  2. 파일을 실행하면 파란 창이 뜹니다 — 추가 정보 → 실행

직접 확인하고 싶다면

내려받은 파일이 올려둔 것과 같은지 검사할 수 있습니다. PowerShell 을 열고 아래를 붙여넣으세요.

Get-FileHash "$env:USERPROFILE\Downloads\NewSchoolSetup_1.0.0.exe" -Algorithm SHA256

결과의 Hash 값이 아래와 같으면 파일이 바뀌지 않은 것입니다.

BA40EAB477711B83542FE80161D8EE667C725F12D82CE375ED4E501583ACCA3E

프로그램의 모든 소스 코드는 GitHub 에 공개돼 있어 누구나 무엇을 하는 프로그램인지 확인할 수 있습니다.

주요 기능 안내

👨‍🎓 체계적인 학급 관리

학생 인적사항과 사진, 누가기록, 학생부 특기사항(NEIS 글자 수 제한 실시간 표시), 자리 배정까지 담임 업무를 한곳에서 처리합니다.

📚 효율적인 수업 관리

수업을 개설해 시간표에 배치하고, 단원·주차별 시수·반별 진도를 관리합니다. 휴강·교체·보강·대강은 그날만 얹히고 평소 시간표는 그대로 둡니다. 수업 일지는 시간표 칸을 누르면 바로 씁니다.

🏫 NEIS 연동 학사일정·급식

나이스(NEIS) OpenAPI를 활용하여 우리 학교의 학사일정과 급식 식단을 자동으로 가져옵니다. 학교 검색으로 처음 한 번만 학교를 지정하면 됩니다.

📅 Google 캘린더 양방향 동기화

Google 계정을 연결하면 학급 행사·수업 일정·할 일을 구글 캘린더와 양쪽으로 맞춥니다. 앱을 켤 때 한 번 맞추고, 자동 동기화를 켜면 정해진 간격(기본 15분)으로 이어서 맞춥니다.

📋 학급일지 · 게시판 · 내보내기

학급일지에 결석·지각·조퇴와 알림장을 남기고, 학급·수업·업무 게시판으로 자료를 모읍니다. 누가기록·학생부·좌석배정·학생카드·학생정보는 Excel·PDF·HTML·CSV 로 한 번에 내보냅니다.

🔒 세련된 UI & 내 PC 안에 머무는 데이터

Windows 11 Fluent Design 을 적용해 쾌적하게 쓸 수 있습니다. 모든 기록은 내 PC 안 파일에 저장되고, 직접 연동한 구글 계정 외에는 어디로도 전송되지 않습니다. 구글 로그인 토큰은 Windows 계정 키로 암호화됩니다(DPAPI). 자동 백업도 지원합니다.
